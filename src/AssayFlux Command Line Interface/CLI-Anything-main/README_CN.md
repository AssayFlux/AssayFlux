# AssayFlux 命令行平台

AssayFlux CLI 旨在成为 AssayFlux 项目的主要开发入口，用于检查、运行、测试和管理 `.af` 项目。本目录中的导入命令自动化代码正在评估中，尚未全部集成。

## 语言优先原则

- `.af` 源代码必须使用 AssayFlux 的规范语言核心进行解析、语义检查和执行。
- 不允许 CLI 服务自行定义与核心不一致的语法。
- 应用专用命令应通过模块化的服务接口提供。
- 命令的权限、副作用、错误和输出格式必须明确。

## 当前状态

**已导入，原生 AssayFlux 集成尚未验证。** 导入的命令工具并不意味着所有命令已成为 AssayFlux 原生功能。
