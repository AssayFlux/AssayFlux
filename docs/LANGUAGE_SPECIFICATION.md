# AssayFlux Language Specification

Version: 0.1.0

## 1. Overview

AssayFlux is a general-purpose programming language designed for scientific computing and interoperability with other programming languages.

## 2. Syntax

AssayFlux uses brace-based syntax for code blocks.

## 3. Design Principles

- Readability
- Scientific computing
- Multi-language interoperability
- Modularity
- Extensibility

## 4. Language Status

This specification describes the initial language design. Implementation will follow after the core grammar is defined.
