# DATASETS

This directory tracks dataset governance metadata, not bulk corpora by default.

Every training/evaluation source requires provenance, license review, permitted-use decision, version/checksum, preprocessing history, quality checks, and split policy. Unknown or incompatible licensing blocks use.

Keep raw/private/large data outside Git unless explicitly reviewed and approved. Never commit secrets or personal data. See [manifests](manifests/README.md) and [sources](sources/README.md).
