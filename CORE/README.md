# CORE

CORE contains shared, system-agnostic interfaces and infrastructure used by more than one AssayFlux component.

Keep contracts small and stable. Do not move Neural-specific algorithms here. A shared abstraction needs a concrete consumer, tests, versioning expectations, and documented compatibility behavior.

See [contracts](contracts/README.md), [architecture](../DOCUMENTATION/ARCHITECTURE.md), and [WORKFLOW.md](../WORKFLOW.md).
