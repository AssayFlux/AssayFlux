# AI Systems

This directory contains independently maintained AssayFlux AI systems.

Each system owns its model, tokenizer/input processing, training and inference code, configuration, evaluation adapters, tests, and system-specific documentation. Systems must not depend on another system's private implementation.

Add a system only with a clear scope, maintainer/ownership, interface, data policy, tests, and acceptance criteria.

Initial system: [NEURAL](NEURAL/README.md).
