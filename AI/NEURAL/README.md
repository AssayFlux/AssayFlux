# AssayFlux Neural

**Status: planned; implementation not yet present.**

The first independent AssayFlux AI system is intended to be a coding-focused experimental model, initially using a small randomly initialized decoder-only Transformer and a custom tokenizer.

Planned components, added incrementally:
- tokenizer and vocabulary format;
- model configuration and architecture;
- training and validation;
- checkpoint save/restore;
- inference;
- evaluation adapters and diagnostics;
- focused unit and integration tests.

Do not add pretrained weights, external API requirements, unreviewed training data, or unsupported capability claims. Follow the Neural phase in [WORKFLOW.md](../../WORKFLOW.md) and the [roadmap](../../DOCUMENTATION/ROADMAP.md).

No model code, trained weights, or demonstrated coding capability is present yet.
