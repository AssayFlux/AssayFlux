Overview

AssayFlux is an experimental programming-language project exploring readable syntax, structured program execution, and interoperability with Python.

The repository contains a language lexer, parser, interpreter, abstract syntax tree, command-line interface, examples, documentation, and automated tests.

External language adapters provide an integration layer for supported runtimes. Availability and compatibility depend on the installed environment.

A foundation for exploring language design and building accessible programming tools.

Getting Started

Install AssayFlux

Requirements: Python 3.10 or newer and Git. 

git clone https://github.com/AssayFlux/AssayFlux.git
cd AssayFlux
python -m pip install -e .
assayflux examples/hello.af

You can also run a source file with python -m assayflux examples/hello.af.

Testing

Run the test suite

python -m pip install -e ".[dev]"
python -m pytest -q

GitHub Actions can execute automated checks for repository changes.
